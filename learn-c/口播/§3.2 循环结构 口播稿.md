同学们好，今天我们来讲**循环结构**。

上节课我们学了选择结构——让程序学会做决策。这节课我们来学另一个重要的控制结构——**循环**。

什么叫循环呢？简单说就是——让程序**重复做某件事**。

大家想想，如果让你输出1到100，你会怎么写？用100行 `printf`？那也太夸张了。循环就是来解决这个问题的——让一段代码反复执行，直到某个条件不再满足为止。

C语言提供了三种循环方式：`while`、`for`、`do-while`。我们一个一个来看。

## while 循环

先看最简单的 `while`：

```c
while (条件)
{
    // 反复执行的代码
}
```

它的执行流程是：先判断条件，条件为真就执行一次循环体，执行完再回来判断条件……一直到条件为假时退出。

来看个例子：输出1到5。

```c
int i = 1;
while (i <= 5)
{
    printf("%d\n", i);
    i++;    // 关键！更新变量
}
```

流程是这样的：i=1 → 检查 `i<=5` 为真 → 输出1 → i=2 → 检查 `i<=5` 为真 → 输出2 → …… → i=6 → 检查 `i<=5` 为假 → 退出。

这里有个**极其重要**的事情：循环体里一定要有能改变条件的手段。比如这里的 `i++`，每循环一次i就增加1，最终i会变成6，条件不成立，循环结束。

如果你忘了写 `i++`，那i永远是1，条件永远成立——这就成了**死循环**，程序会永远跑下去，只能按 Ctrl+C 强制终止。

## for 循环

`while` 虽然简单，但初始化、条件判断、变量更新是分开写的，有点散。`for` 循环把它们集中到了一起：

```
for (初始化; 条件; 更新)
{
    // 反复执行的代码
}
```

三个部分各司其职：
1. **初始化**：刚进入循环时执行一次，通常用来定义计数器
2. **条件**：每次循环前检查，为真继续，为假退出
3. **更新**：每次循环结束后执行，用来改变计数器

用 for 重写上面的例子：

```c
for (int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}
```

是不是比 while 更紧凑？执行顺序是这样的：

第一步：执行 `int i = 1`（只做一次）
第二步：判断 `i <= 5`——为真就进循环体，为假就退出
第三步：执行循环体里的 `printf`
第四步：执行 `i++`
第五步：回到第二步

这么看，for 和 while 其实是可以互相转换的。但 for 把循环相关的三要素写在一起，代码更清晰，不容易漏掉更新语句。

for 的三个部分都可以省略，但两个分号不能省：

```c
for (;;)    // 死循环
```

### 总结一下什么时候用 for

当你**知道要循环多少次**的时候，用 for 最合适。比如"输出1到100"、"遍历数组"这些场景。

## do-while 循环

`do-while` 和 while 的区别在于：**先执行一次循环体，再判断条件**。所以它至少会执行一次。

```c
do
{
    // 反复执行的代码
}
while (条件);    // 注意这里有分号！
```

对比一下 while 和 do-while：

```c
int x = 10;

while (x < 5)           // 条件一开始就不成立
{
    printf("不会执行");   // 这行不会被执行
}

do
{
    printf("至少执行一次"); // 这行会执行一次
}
while (x < 5);           // 然后条件不成立，退出
```

while 是"先判断后执行"，do-while 是"先执行后判断"。实际开发中 while 和 for 用得更多，do-while 用得少一些，但在某些场景（比如先读取用户输入再判断是否合法）它就很方便。

## break 和 continue

循环里有两个很有用的控制语句：`break` 和 `continue`。

### break：跳出循环

`break` 用来**立即结束整个循环**，不再执行剩余的循环体，也不再判断条件。

比如，从1到100中找第一个能被7整除的数，找到了就停下来：

```c
for (int i = 1; i <= 100; i++)
{
    if (i % 7 == 0)
    {
        printf("找到：%d", i);
        break;    // 找到了，没必要继续循环了
    }
}
```

用考试来类比：break 就像考试铃响了——停笔，交卷，全部结束。

### continue：跳过本轮

`continue` 和 break 不同，它只是**跳过当前这一次循环**，然后继续下一次。

比如输出1到10中的奇数：

```c
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        continue;    // 偶数跳过，不输出
    }
    printf("%d ", i);
}
// 输出：1 3 5 7 9
```

还用考试类比：continue 就像你有一道题不会——先跳过，做后面的题，试卷还是要交的。

有一点要注意：break 和 continue 都只作用于**最内层**的循环。如果有嵌套循环，它们只影响自己所在的那一层。

## 嵌套循环

循环里面可以再套循环。比如输出九九乘法表：

```c
for (int i = 1; i <= 9; i++)
{
    for (int j = 1; j <= i; j++)
    {
        printf("%d×%d=%d\t", j, i, i * j);
    }
    printf("\n");
}
```

执行过程是这样的：外层 i=1 时，内层 j 从1到1；外层 i=2 时，内层 j 从1到2；外层 i=3 时，内层 j 从1到3……以此类推。

可以理解为：外层循环走一步，内层循环走完整一轮。

## 常见陷阱

最后讲几个新手容易踩的坑。

**陷阱一：死循环**

忘记更新循环变量，条件永远为真。

**陷阱二：循环条件写反**

```c
// 想从5到1递减
for (int i = 5; i <= 1; i--)    // 错！条件一开始就不成立
for (int i = 5; i >= 1; i--)    // 正确
```

**陷阱三：分号放错位置**

```c
for (int i = 1; i <= 5; i++);   // 多写了个分号！循环体是空的
{
    printf("%d", i);             // 这行只执行一次，不在循环里
}
```

分号加在 for 后面，循环体就变成了一个空语句，后面的代码块跟循环没关系。

## 综合示例

我们把上节课的猜数字游戏升级一下——加上循环，让用户可以一直猜，直到猜对为止：

```c
int answer = 42;
int guess;

while (1)    // 死循环，靠内部 break 退出
{
    printf("请输入：");
    scanf("%d", &guess);

    if (guess == answer)
    {
        printf("恭喜，猜对了！");
        break;    // 猜对了，退出循环
    }
    else if (guess > answer)
        printf("猜大了。");
    else
        printf("猜小了。");
}
```

`while (1)` 是一个无限循环，条件永远为真。但我们通过内部的 `break` 在猜对时退出——这种模式在实际编程中很常见。

## 总结

好，我们来回顾一下今天的内容：

- **while**：先判断后执行，注意更新循环变量
- **for**：初始化、条件、更新写在一起，适合计数循环
- **do-while**：先执行后判断，至少执行一次
- **break**：跳出整个循环
- **continue**：跳过当前这一次
- **嵌套循环**：外层走一步，内层走一轮
- **三个常见陷阱**：死循环、条件写反、分号放错

循环让程序有了"批量处理"的能力。如果说选择结构让程序有了"智能"，那循环结构就让程序有了"效率"。

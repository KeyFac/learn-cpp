# §3.1 选择结构 口播稿

---

同学们好，今天我们来讲**选择结构**。

什么叫选择结构呢？简单说就是——让程序学会"看情况办事"。

大家想一下，我们平时做决定是怎么做的？如果今天下雨，我就带伞；如果没下雨，我就不带。这就是一个典型的选择。程序也是一样的道理——它需要根据不同的条件，执行不同的代码。

好，那我们来看看C语言里最基础的选择工具：**if 语句**。

## if 语句

if 的写法很简单：

```
if (条件)
{
    // 条件成立时执行的代码
}
```

它的意思是：如果这个条件成立（在C语言里，只要条件的结果不是0，就算成立），就执行大括号里面的代码。如果条件不成立呢？那就跳过，什么都不做。

来看个具体的例子——

```c
int score = 85;

if (score >= 60)
{
    printf("恭喜，及格了！\n");
}
```

这段代码会输出"恭喜，及格了！"，因为85确实大于等于60嘛。

这里有个小细节：如果 if 后面只有一条语句，可以省略大括号。但我**强烈建议**你始终加上大括号。为什么呢？因为以后你如果在 if 里再加一行代码，很容易忘记加括号，导致逻辑错误——你以为是 if 里面的，实际上它在 if 外面。这个坑无数人踩过，希望大家一开始就养成好习惯。

## 关系运算符

说到条件判断，就绕不开比较。C语言提供了六个关系运算符：

- `==` 等于
- `!=` 不等于
- `>` 大于
- `<` 小于
- `>=` 大于等于
- `<=` 小于等于

这里要特别强调一个**所有初学者都会犯的错误**：判断两个东西是否相等，要用**两个等号** `==`，而不是一个等号 `=`。

```
if (a = 5)     // 糟糕！这不是判断，是赋值！
```

一个等号是赋值——把5赋给a，然后这个表达式的值就是5，在C语言里非零即为真，所以这个条件永远成立。这不是你想要的效果。

## 逻辑运算符

有时候一个条件不够用，我们需要组合多个条件。比如：要同时满足"年龄大于等于18"和"有身份证"两个条件才能上网吧。这时候就需要逻辑运算符：

- `&&` 表示"且"——两边都为真时，结果才为真
- `||` 表示"或"——只要有一边为真，结果就为真
- `!` 表示"非"——把真变成假，假变成真

举个例子：

```c
if (age >= 18 && hasID == 1)
{
    printf("可以进入网吧\n");
}
```

这里 `&&` 左边要成立、右边也要成立，整体才成立。两个条件都得满足。

### 短路求值

`&&` 和 `||` 有一个很重要的特性，叫**短路求值**。什么叫短路呢？就是如果左边的条件已经能决定结果了，右边就不执行了。

比如 `&&`：左边是假，那整体一定是假，右边根本不用看。
比如 `||`：左边是真，那整体一定是真，右边也不用看了。

这个特性不光是为了效率，还能用来**避免错误**：

```c
if (divisor != 0 && 10 / divisor > 1)
```

如果 `divisor` 是0，左边 `divisor != 0` 为假，短路了，右边 `10 / divisor` 根本不会执行——这就安全地避免了一次"除以0"的错误。

## if-else 语句

光有 if 还不够，很多时候我们还需要"否则"的情况。比如：如果及格了显示"及格"，否则显示"不及格"。

```c
if (score >= 60)
{
    printf("及格了！\n");
}
else
{
    printf("不及格。\n");
}
```

有 if 有 else，这才是一个完整的二选一。

## else if 多分支

那如果有多个条件要依次判断呢？用 `else if`。

成绩等级评定就是一个经典例子：

```c
if (score >= 90)
    printf("A\n");
else if (score >= 80)
    printf("B\n");
else if (score >= 70)
    printf("C\n");
else if (score >= 60)
    printf("D\n");
else
    printf("F\n");
```

这里要注意一个非常重要的点：**判断顺序必须从严到宽**。

什么意思呢？就是先判断最高分，再依次往下。如果反过来，先写 `score >= 60`，再写 `score >= 90`——那考了95分的人，第一步就被 `score >= 60` 截住了，永远不会到达"优秀"的判定。

## 三元运算符

C语言里还有一个简洁的写法叫**三元运算符** `? :`，适合简单的二选一赋值：

```c
int max = (a > b) ? a : b;
```

如果 a 大于 b，整个表达式的值就是 a，否则是 b。相当于：

```c
int max;
if (a > b)
    max = a;
else
    max = b;
```

三元运算符能让代码更简洁，但仅限于简单的二选一。如果逻辑复杂了，还是用 if-else 更清晰，不要为了炫技而牺牲可读性。

## switch-case 语句

最后来说说 **switch-case**。

假如我们要根据用户输入的数字1到7，输出对应的星期几。用 `else if` 当然可以写，但会显得很啰嗦。这时候 `switch` 就更合适：

```c
switch (day)
{
    case 1:
        printf("星期一\n");
        break;
    case 2:
        printf("星期二\n");
        break;
    // ... 以此类推
    default:
        printf("输入无效\n");
}
```

switch 的意思是：拿表达式的值去和每个 case 后面的常量比较，匹配上了就执行对应的代码。

有几个要点：
1. switch 后面只能跟整数类型，不能用小数或字符串
2. 每个 case 后面必须是常量，不能是变量
3. **每个 case 后面要加 break**，不然会"穿透"到下一个 case

### 穿透（fall-through）

说到穿透，这其实是一把双刃剑。忘了写 break，程序会继续往下执行后面的 case，这通常是个bug：

```c
int n = 2;
switch (n)
{
    case 1: printf("一");
    case 2: printf("二");    // 输出"二"
    case 3: printf("三");    // 没有break，继续执行到这里！输出"三"
}
// 最终输出："二三"——这不是我们想要的
```

但穿透也可以**巧妙利用**。比如判断季节：

```c
switch (month)
{
    case 3:
    case 4:
    case 5:
        printf("春季\n");
        break;
    case 6:
    case 7:
    case 8:
        printf("夏季\n");
        break;
    // ...
}
```

三个月共用同一段代码，省去了重复写条件判断的麻烦。

## 总结

好，我们来快速回顾一下今天讲的内容：

- **if**：最基本的条件判断
- **关系运算符**：`==` `!=` `>` `<` `>=` `<=`——特别注意 `==` 和 `=` 的区别
- **逻辑运算符**：`&&`（且）、`||`（或）、`!`（非）
- **短路求值**：左边能决定结果时右边不执行
- **if-else**：二选一
- **else if**：多分支，注意顺序
- **三元运算符** `? :`：简洁的二选一，但别滥用
- **switch-case**：多路分支利器，别忘了 break

选择结构是程序逻辑的基石——没有选择，程序只是一条直线。有了选择，程序才有了"智能"。希望大家学完这一节之后，能够灵活运用这些知识，写出有判断力的代码。

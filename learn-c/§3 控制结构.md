# §3.1 选择结构

程序的默认执行顺序是逐行往下跑。但很多时候，我们需要让程序根据不同的情况"做决策"——如果某个条件成立，就走这条路；否则走另一条路。这就是**选择结构**。

在日常生活中也一样：如果下雨就带伞，如果饿了就吃饭——代码里也是如此。

## if 语句

最基本的条件判断：

```c
if (条件)
{
    // 条件为真（非零）时执行的代码
}
```

如果条件成立（在C语言中，非零即为"真"），就执行大括号里的代码；否则跳过。

```c
#include <stdio.h>

int main()
{
    int score = 85;

    if (score >= 60)
    {
        printf("恭喜，及格了！\n");
    }

    return 0;
}
```

如果 if 后面只有**一条语句**，可以省略大括号：

```c
if (score >= 60)
    printf("及格了！\n");    // 只有一条语句，可以不用大括号

// 但如果有多条语句，必须用大括号括起来
if (score >= 60)
    printf("第一行\n");      // 这一行属于 if
    printf("第二行\n");      // 注意！这一行不属于 if，总会执行
```

> 建议：即使只有一条语句，也始终加上大括号。这样可以避免以后添加代码时不小心搞错归属。

## 关系运算符

条件判断离不开比较：

| 运算符 | 含义 | 举例 | 结果为真的情况 |
|-------|------|------|--------------|
| `==` | 等于 | `a == b` | a 等于 b |
| `!=` | 不等于 | `a != b` | a 不等于 b |
| `>` | 大于 | `a > b` | a 大于 b |
| `<` | 小于 | `a < b` | a 小于 b |
| `>=` | 大于等于 | `a >= b` | a 大于等于 b |
| `<=` | 小于等于 | `a <= b` | a 小于等于 b |

**特别注意**：判断相等要用 `==`（两个等号），而不是 `=`（一个等号是赋值）。这是初学者最容易犯的错误之一。

```c
if (a = 5)     // 这不是判断 a 是否等于 5
                // 而是把 5 赋给 a，然后条件恒为"真"
```

## 逻辑运算符

有时一个条件不够，需要组合多个条件：

- `&&` — 且（与），两边都为真时结果才为真。例如：`a > 0 && a < 100`
- `||` — 或，任一边为真时结果就为真。例如：`a < 0 || a > 100`
- `!` — 非（取反），真变假、假变真。例如：`!(a == 0)`


```c
int age = 25;
int hasID = 1;    // 1 表示"有"，0 表示"没有"

// 且：两个条件都要满足
if (age >= 18 && hasID == 1)
{
    printf("可以进入网吧\n");
}

// 或：满足一个就行
if (score < 60 || score > 100)
{
    printf("成绩异常\n");
}

// 非：取反
if (!hasID)
{
    printf("没有身份证\n");
}
```

### 短路求值

`&&` 和 `||` 有一个重要特性：**短路求值**。意思是如果能从左边的条件直接推断出结果，右边的条件就不会被执行。

```c
int a = 5, b = 0;

// && 左边为假（a > 10 不成立），右边根本不会执行
if (a > 10 && b++ > 0) { }

printf("%d\n", b);    // b 还是 0，因为 b++ 没被执行
```

利用这个特性可以避免一些错误，比如除数为0：

```c
int divisor = 0;
if (divisor != 0 && 10 / divisor > 1)  // 安全！左边为假，右边不会执行
```

## if-else 语句

有了 else，就可以处理"否则"的情况：

```c
if (条件)
{
    // 条件成立时执行
}
else
{
    // 条件不成立时执行
}
```

```c
#include <stdio.h>

int main()
{
    int score;
    printf("请输入成绩：");
    scanf("%d", &score);

    if (score >= 60)
    {
        printf("及格了！棒！\n");
    }
    else
    {
        printf("不及格，继续加油。\n");
    }

    return 0;
}
```

## else if 多分支

当有多个条件需要依次判断时，使用 `else if`：

```c
if (条件1)
{
    // 条件1成立
}
else if (条件2)
{
    // 条件1不成立，但条件2成立
}
else if (条件3)
{
    // 条件1、2都不成立，但条件3成立
}
else
{
    // 以上所有条件都不成立
}
```

```c
// 成绩等级评定
#include <stdio.h>

int main()
{
    int score;
    printf("请输入成绩：");
    scanf("%d", &score);

    if (score >= 90)
    {
        printf("等级：A\n");
    }
    else if (score >= 80)
    {
        printf("等级：B\n");
    }
    else if (score >= 70)
    {
        printf("等级：C\n");
    }
    else if (score >= 60)
    {
        printf("等级：D\n");
    }
    else
    {
        printf("等级：F（不及格）\n");
    }

    return 0;
}
```

> 注意 `else if` 的顺序很重要。如果写成 `score >= 60` 在前，`score >= 90` 在后，那么考了95分的人会被先归入"及格"而不会进入"A"等级。

## 条件（三元）运算符

C语言里有一个简洁的条件运算符 `? :`，是三目运算符（有三个操作数）：

```c
条件 ? 值为真时的结果 : 值为假时的结果
```

```c
int a = 10, b = 20;
int max = (a > b) ? a : b;    // 取较大的值
printf("最大值是：%d
", max);  // 输出 20
```

相当于：

```c
int max;
if (a > b)
    max = a;
else
    max = b;
```

三元运算符适合简单的二选一赋值，能让代码更简洁。但如果逻辑复杂，还是用 if-else 更清晰。

## switch-case 语句

当要根据一个变量的**多个具体取值**做不同的事情时，`switch` 比长长的 `else if` 更清晰：

```c
switch (表达式)
{
    case 值1:
        // 表达式等于值1时执行
        break;            // 跳出 switch，继续执行后面的代码
    case 值2:
        // 表达式等于值2时执行
        break;
    case 值3:
        // 表达式等于值3时执行
        break;
    default:
        // 以上所有值都不匹配时执行（可省略）
}
```

```c
#include <stdio.h>

int main()
{
    int day;
    printf("请输入星期几（1-7）：");
    scanf("%d", &day);

    switch (day)
    {
        case 1:
            printf("星期一\n");
            break;
        case 2:
            printf("星期二\n");
            break;
        case 3:
            printf("星期三\n");
            break;
        case 4:
            printf("星期四\n");
            break;
        case 5:
            printf("星期五\n");
            break;
        case 6:
            printf("星期六\n");
            break;
        case 7:
            printf("星期日\n");
            break;
        default:
            printf("输入无效，请输入1-7之间的数字。\n");
    }

    return 0;
}
```

### break 与 fall-through

`break` 的作用是跳出 switch。如果没有 `break`，程序会继续往下执行后面的 case，这叫 **fall-through**：

```c
int n = 2;
switch (n)
{
    case 1:
        printf("一");
    case 2:
        printf("二");    // n=2，从这里进入
    case 3:
        printf("三");    // 没有 break，继续执行到这里
}
// 输出："二三"
```

fall-through 不全是坏事，有时可以巧妙利用：

```c
int month = 3;
switch (month)
{
    case 3:
    case 4:
    case 5:
        printf("春季\n");
        break;
    case 6:
    case 7:
    case 8:
        printf("夏季\n");
        break;
    case 9:
    case 10:
    case 11:
        printf("秋季\n");
        break;
    case 12:
    case 1:
    case 2:
        printf("冬季\n");
        break;
    default:
        printf("无效月份\n");
}
```

> 注意：switch 的表达式只能是整数类型（`int`、`char` 等），不能用于 `double` 或字符串。

## 综合示例：猜数字

```c
#include <stdio.h>

int main()
{
    int answer = 42;    // 预设的答案
    int guess;

    printf("猜一个数字（1-100）：");
    scanf("%d", &guess);

    if (guess == answer)
    {
        printf("恭喜你，猜对了！\n");
    }
    else if (guess > answer)
    {
        printf("猜大了。\n");
    }
    else
    {
        printf("猜小了。\n");
    }

    return 0;
}
```

## 本章小结

- **if**：最基本的条件判断，条件为真时执行代码
- **关系运算符**：`==` `!=` `>` `<` `>=` `<=`
- **逻辑运算符**：`&&`（且） `||`（或） `!`（非）
- **短路求值**：`&&` 和 `||` 左边能决定结果时，右边不执行
- **else**：处理"否则"的情况
- **else if**：多分支判断，注意顺序！
- **三元运算符**：`条件 ? 值1 : 值2`，简单的二选一
- **switch-case**：根据整数取值做多路分支，别忘了 `break`
- **fall-through**：没有 break 时会继续往下执行，可以巧妙利用

# §3.2 循环结构

有时候我们需要重复做某件事很多次。比如：输出1到100、反复读取用户输入直到正确、遍历数组中的每个元素。如果用手写的方式，100次输出就要写100行 `printf`，显然不现实。

这时候就需要**循环**——让一段代码反复执行，直到某个条件不再满足为止。

C语言提供了三种循环方式：`while`、`for`、`do-while`。

## while 循环

最简单的循环结构：

```c
while (条件)
{
    // 反复执行的代码，直到条件变为假
}
```

每次执行大括号里的代码之前，先检查条件。条件为真就执行一次，然后再次检查……直到条件为假时退出。

```c
// 输出 1 到 5
#include <stdio.h>

int main()
{
    int i = 1;

    while (i <= 5)
    {
        printf("%d\n", i);
        i++;          // 别忘了更新变量，否则会死循环
    }

    return 0;
}
```

运行过程：i=1 → 输出1 → i=2 → 输出2 → i=3 → 输出3 → i=4 → 输出4 → i=5 → 输出5 → i=6 → 条件 `6 <= 5` 为假 → 退出循环。

> **重要**：循环体内一定要有能改变条件的手段（比如 `i++`），否则条件永远为真，就成了**死循环**。

## for 循环

`for` 循环把初始化、条件判断、变量更新集中在一起，结构更紧凑：

```c
for (初始化; 条件; 更新)
{
    // 反复执行的代码
}
```

三个部分的含义：
1. **初始化** — 进入循环前执行一次，通常用来定义计数器变量
2. **条件** — 每次循环前检查，为真则继续，为假则退出
3. **更新** — 每次循环结束后执行，通常用来改变计数器

```c
// 用 for 输出 1 到 5
#include <stdio.h>

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}
```

执行顺序：
1. 执行 `int i = 1`（只做一次）
2. 判断 `i <= 5` → 真则进入循环体，假则退出
3. 执行循环体 `printf("%d
", i)`
4. 执行 `i++`
5. 回到步骤2

### for 的省略写法

三个部分都可以省略，但分号不能省：

```c
int i = 1;
for (; i <= 5;)    // 省略初始化和更新，相当于 while
{
    printf("%d\n", i);
    i++;
}

for (;;)           // 三个部分都省略，就是死循环
{
    // 永远执行
}
```

## do-while 循环

`do-while` 和 `while` 的区别是：**先执行一次循环体，再判断条件**。所以循环体至少会执行一次。

```c
do
{
    // 反复执行的代码
}
while (条件);    // 注意这里有分号！
```

```c
// 至少执行一次的例子
#include <stdio.h>

int main()
{
    int n = 1;

    do
    {
        printf("%d\n", n);
        n++;
    }
    while (n <= 5);

    return 0;
}
```

```c
// while 和 do-while 的对比
int x = 10;

while (x < 5)        // 条件一开始就不成立
{
    printf("不会执行\n");   // 这行不会被执行
}

do
{
    printf("至少执行一次\n");  // 这行会执行一次
}
while (x < 5);        // 然后条件不成立，退出
```

## break 和 continue

### break：跳出循环

`break` 立即结束当前循环，不再执行循环体中剩余的代码，也不再判断条件。

```c
// 找到第一个能被 7 整除的数
for (int i = 1; i <= 100; i++)
{
    if (i % 7 == 0)
    {
        printf("找到：%d\n", i);
        break;          // 找到了，没必要继续循环
    }
}
```

### continue：跳过本轮

`continue` 跳过当前这一次循环中剩下的代码，直接进入下一次循环。

```c
// 输出 1 到 10 中的奇数
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        continue;       // 偶数跳过，不输出
    }
    printf("%d ", i);
}
// 输出：1 3 5 7 9
```

| 语句 | 作用 | 类比 |
|------|------|------|
| `break` | 跳出整个循环 | 考试时响铃了，停笔交卷 |
| `continue` | 跳过当前这一次 | 这道题不会，先跳过做下一题 |

> `break` 和 `continue` 都只作用于**最内层**的循环。如果有嵌套循环，它们只影响自己所在的那一层。

## 嵌套循环

循环里面可以再套循环：

```c
// 输出九九乘法表
#include <stdio.h>

int main()
{
    for (int i = 1; i <= 9; i++)
    {
        for (int j = 1; j <= i; j++)
        {
            printf("%d×%d=%d\n", j, i, i * j);
        }
        printf("\n");    // 每行换行
    }

    return 0;
}
```

执行过程：外层 i=1 → 内层 j=1（输出 1×1=1，换行）→ 外层 i=2 → 内层 j=1,2（输出 1×2=2, 2×2=4，换行）→ ... 直到 i=9。

## 循环的选择

| 场景 | 推荐用 |
|------|--------|
| 知道明确的循环次数 | `for` |
| 不知道次数，只知道条件 | `while` |
| 至少需要执行一次 | `do-while` |

一般来说，用 `for` 的场景最多——计数循环用它最清晰。

## 常见陷阱

### 1. 死循环

```c
// 忘记更新变量
int i = 1;
while (i <= 5)
{
    printf("永远执行\n");  // i 始终是 1，条件始终为真
}
```

如果不小心写出了死循环，按 Ctrl+C 强制终止程序。

### 2. 循环条件写反

```c
// 本意是 i 从 5 到 1
for (int i = 5; i >= 1; i--)    // 正确
for (int i = 5; i <= 1; i--)    // 错误！条件一开始就不成立
```

### 3. 分号放错位置

```c
for (int i = 1; i <= 5; i++);   // 多了个分号！循环体是空语句
{
    printf("%d\n", i);           // 这行只执行一次
}
```

## 综合示例：猜数字（带循环）

```c
#include <stdio.h>

int main()
{
    int answer = 42;
    int guess;

    printf("猜一个数字（1-100）：\n");

    // 用 while 循环反复猜，直到猜对
    while (1)    // 死循环，靠内部 break 退出
    {
        printf("请输入：");
        scanf("%d", &guess);

        if (guess == answer)
        {
            printf("恭喜，猜对了！\n");
            break;            // 猜对了，退出循环
        }
        else if (guess > answer)
        {
            printf("猜大了。\n");
        }
        else
        {
            printf("猜小了。\n");
        }
    }

    return 0;
}
```

## 本章小结

- **while**：先判断条件，为真则执行循环体
- **for**：初始化 + 条件 + 更新，适合计数循环
- **do-while**：先执行一次循环体，再判断条件
- **break**：跳出整个循环
- **continue**：跳过本次循环的剩余部分
- **嵌套循环**：循环里面套循环，外层跑一次、内层跑完整一轮
- **常见陷阱**：别忘了更新变量、分号不要放错位置、条件不要写反

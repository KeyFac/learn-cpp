# §1.1引言
C语言，作为部分专业在大一开设的课程，常常让人感到难以学习。在正式开始之前，我们先对C语言做一个简单的介绍。

C语言是一种面向过程的高级编程语言，由丹尼斯·里奇（Dennis Ritchie）于1972年在贝尔实验室开发，最初用于编写UNIX操作系统。经过数十年的发展，C语言凭借其简洁高效、底层能力强、可移植性好等特点，至今仍是计算机科学领域最重要的基础语言之一。

对于初学者而言，C语言的"难"往往不在于语法本身——它的关键字不过几十个，语法规则也相对简明——而在于它要求我们真正理解计算机的工作方式：内存如何分配、指针如何运作、程序如何一步步执行。这些内容与我们日常使用电脑的直观感受相去甚远，因此容易让人产生挫败感。

但请放心，难并不意味着学不会。恰恰相反，正是因为C语言逼迫我们直面底层逻辑，它才成为锻炼编程思维最好的起点。一旦迈过这道门槛，你会发现后续学习任何一门新语言都会变得轻松许多。

接下来，就让我们从最基础的地方开始，一步一步走进C语言的世界。

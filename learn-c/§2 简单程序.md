# §2.1 Hello World!
在编程界，有一个习惯：为了测试编程环境有无问题，我们会写一个示例程序。同时，这也成了新人学习一门语言的第一个程序。
很多新手经常忘记切到英文输入法，不要忘了。
Hello world程序要做的很简单，就是输出一行”Hello World!“。我们接下来一行一行拆解这个程序。
注意，以下的内容，你**不需要**完全听懂，也可以完全**没听懂**，只需要脑子里有个大概印象就可以了。
```c 2.1hw.c
#include <stdio.h>
int main()
{
	printf("Hello World!\n");
	return 0;
}
```
1. 第一行 ```#include<stdio.h>```的功能是引入头文件stdio，告诉电脑我们需要输入输出的功能。注意#不要漏掉。
2. ```int main()```声明了一个名为main的函数。main意为主要，告诉电脑：程序从这里开始。什么是函数呢？函数就是一个根据给定的参数执行一定代码最后返回一个值的东西。我们会在后面详细讲。不能理解的话，就先把这部分当做“固定格式”好了。
3. main函数下面用一对大括号（花括号）包含了一段代码。这就是main函数的内容。
4. ```printf("Hello World!");```这句代码完成了输出“Hello World!”的工作。我们来关注几个重要的点。
	- printf也是一个函数，就像main一样。它的功能是输出内容。在使用它时，需要在名称后跟一对括号。
	- 括号内的内容被称作“参数”。这里的参数是"Hello World!"，也就是我们希望输出的内容。
	- "\n"是换行符，让输出另起一行开始。
	- 最后的分号不要忘记，是告诉电脑我们完成了一个任务。
5. ```return 0```的意思是让main函数返回0，意思是我们这个函数没有错误。
以上就是Hello World程序的全部内容。或许你还有很多没理解，没关系，先跟着一起把这段代码写完，保存，编译运行。如果没有任何报错，恭喜你！你已经通过了学C语言的第一关。
在Dev-C++中，编译运行的快捷键是F11。

# §2.2 变量与运算

## 变量：给数据取个名字

在程序中，我们经常需要临时存放一些数据。比如你输入了一个数字，我们要把它记住，然后拿去做计算。这时候就需要用到**变量**。

变量就像一个有名字的盒子，我们可以往里面放数据，也可以从中取出数据。每个盒子只能放特定类型的东西——有的盒子只能放整数，有的只能放小数，有的只能放单个字符。

### 声明变量

在使用变量之前，必须先声明它，告诉电脑"我要一个这样的盒子"：

```c
int age;           // 声明一个整数类型的变量，名叫 age
double pi;         // 声明一个双精度小数类型的变量（精度更高）
char grade;        // 声明一个字符类型的变量
```

也可以在声明的同时赋一个初始值：

```c
int age = 18;
double pi = 3.14159;
char grade = 'A';
```

### 常见的变量类型

| 类型       | 名称     | 举例                      | 说明                    |
| -------- | ------ | ----------------------- | --------------------- |
| `int`    | 整型     | `int a = 10;`           | 存放整数，如 -100、0、2024    |
| `double` | 双精度浮点型 | `double d = 3.1415926;` | 存放小数（约15-16位有效数字），更精确 |
| `char`   | 字符型    | `char c = 'A';`         | 存放单个字符，用**单引号**括起来    |

### 变量命名规则

给变量取名时，要遵守以下规则：

1. 只能包含字母、数字和下划线（`_`）
2. 不能以数字开头
3. 不能是C语言的关键字（如 `int`、`return`、`if` 等）
4. **区分大小写**——`age` 和 `Age` 是两个不同的变量

合法名字的例子：`score`、`_count`、`studentName`、`num2`

非法名字的例子：`2ndPlace`（数字开头）、`my-name`（包含连字符）、`int`（关键字）

> 建议：给变量起**有意义**的名字。`score` 比 `s` 好得多，`total_score` 比 `a` 好得多。几个月后再看自己的代码，你会感谢自己的。

## 赋值与使用

用 `=` 号给变量赋值。注意，这里的 `=` 是"赋值"的意思，不是数学上的"等于"。

```c
int a;
a = 5;          // 把 5 放进变量 a
a = 10;         // 把 10 放进变量 a——原来的 5 被覆盖了

int b = a + 3;  // 先把 a 的值取出来（10），加上 3，再赋给 b
```

```c
// 完整的例子
#include <stdio.h>

int main()
{
    int x = 10;
    int y = 20;
    int sum = x + y;

    printf("x = %d\n", x);
    printf("y = %d\n", y);
    printf("sum = %d\n", sum);

    return 0;
}
```

### printf 的格式化输出

你可能注意到了上面代码里的 `%d`。这是 printf 的**格式说明符**，用来告诉程序"这里要输出一个整数"。

常用的格式说明符：

| 格式说明符  | 对应类型               | 说明     |
| ------ | ------------------ | ------ |
| `%d`   | `int`              | 输出整数   |
| `%f`   | `float` / `double` | 输出小数   |
| `%.2f` | `float` / `double` | 保留两位小数 |
| `%c`   | `char`             | 输出单个字符 |
| `%s`   | 字符串                | 输出一串文字 |

```c
printf("我的年龄是%d岁\n", age);       // %d 会被变量 age 的值替换
printf("圆周率 ≈ %.2f\n", pi);         // 输出：圆周率 ≈ 3.14
printf("成绩：%d分，等级：%c\n", score, grade);  // 可以一次输出多个变量
```

## 算术运算

C语言支持基本的数学运算：

| 运算符 | 含义      | 举例       | 结果             |
| --- | ------- | -------- | -------------- |
| `+` | 加法      | `3 + 5`  | `8`            |
| `-` | 减法      | `10 - 4` | `6`            |
| `*` | 乘法      | `4 * 7`  | `28`           |
| `/` | 除法      | `10 / 3` | `3`（整数除法，往下看↓） |
| `%` | 取余（模运算） | `10 % 3` | `1`（10除以3的余数）  |

### 整数除法的陷阱

两个整数相除，结果**还是整数**，小数部分会被直接丢弃（不是四舍五入，是直接截断）：

```c
int a = 10 / 3;    // a = 3，而不是 3.333...
int b = 5 / 2;     // b = 2，而不是 2.5
double c = 10/3;
```

想要得到小数结果，可以让其中一个操作数变成小数：

```c
double c = 10 / 3.0;     // c = 3.333333
double d = 10.0 / 3;     // d = 3.333333
double e = (double)10 / 3;  // 强制类型转换，也是 3.333333
```

### 取余运算 `%`

`%` 求两个整数相除的**余数**，非常实用：

```c
int r = 17 % 5;     // r = 2（17除以5得3余2）
```

用途举例：判断奇偶（`n % 2 == 0` 为偶数），判断能否整除，取数字的个位（`n % 10`）等。

### 复合赋值运算符

把运算和赋值结合起来，可以让代码更简洁：

```c
int n = 10;
n += 5;     // 相当于 n = n + 5，结果是 15
n -= 3;     // 相当于 n = n - 3，结果是 12
n *= 2;     // 相当于 n = n * 2，结果是 24
n /= 4;     // 相当于 n = n / 4，结果是 6
n %= 3;     // 相当于 n = n % 3，结果是 0
```

### 自增与自减

`++` 和 `--` 是C语言中很常见的简写，分别表示加1和减1：

```c
int count = 5;
count++;          // count 变成 6
count--;          // count 变回 5
```

这里有前后置之分：

```c
int a = 5, b;
b = a++;          // 先把 a 的值赋给 b（b=5），然后 a 自增（a=6）
```

```c
int a = 5, b;
b = ++a;          // a 先自增（a=6），然后把 a 的值赋给 b（b=6）
```

**总结**：`++` 在前，先自增再使用；`++` 在后，先使用再自增。初学者建议分开写，避免混淆。

## 用户输入：scanf

仅仅输出还不够，我们还需要接收用户的输入。`scanf` 函数可以做到这一点：

```c
int number;
scanf("%d", &number);     // 等待用户输入一个整数，存到 number 里
```

注意 `scanf` 的两个要点：
1. 第一个参数和 printf 一样，是格式说明符，告诉程序要读入什么类型的数据
2. **变量名前面要加 `&`**（取地址符号），原因我们讲指针时会说明，先记住这个规则

```c
// 完整例子：计算两个数的和
#include <stdio.h>

int main()
{
    int a, b, sum;

    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);     // 连续读入两个整数

    sum = a + b;
    printf("%d + %d = %d\n", a, b, sum);

    return 0;
}
```

## 综合示例：简单的计算器

```c
#include <stdio.h>

int main()
{
    int a, b;

    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);

    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d（整数除法）\n", a, b, a / b);
    printf("%d %% %d = %d（取余）\n", a, b, a % b);

    return 0;
}
```

> 注意：printf 里要输出 `%` 本身，需要写两个 `%%`。

## 本章小结

- **变量**是存放数据的"盒子"，使用前必须先声明类型
- **命名规则**：字母/数字/下划线，不能数字开头，不能是关键字
- **格式说明符**：`%d`（整数）、`%f`（小数）、`%c`（字符）
- **算术运算符**：`+` `-` `*` `/` `%`
- **整数除法**会截断小数部分
- **复合赋值**：`+=` `-=` `*=` `/=` `%=`
- **自增自减**：`++` `--`，注意前后置的区别
- **scanf** 读入用户输入，变量名前面加 `&`

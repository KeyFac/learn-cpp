# §2.1 Hello World!
在编程界，有一个习惯：为了测试编程环境有无问题，我们会写一个示例程序。同时，这也成了新人学习一门语言的第一个程序。
很多新手经常忘记切到英文输入法，不要忘了。
Hello world程序要做的很简单，就是输出一行”Hello World!“。我们接下来一行一行拆解这个程序。
注意，以下的内容，你**不需要**完全听懂，也可以完全**没听懂**，只需要脑子里有个大概印象就可以了。
```c 2.1hw.c
#include <stdio.h>
int main()
{
	printf("Hello World!");
	return 0;
}
```
1. 第一行 ```#include<stdio.h>```的功能是引入头文件stdio，告诉电脑我们需要输入输出的功能。注意#不要漏掉。
2. ```int main()```声明了一个名为main的函数。main意为主要，告诉电脑：程序从这里开始。什么是函数呢？函数就是一个根据给定的参数执行一定代码最后返回一个值的东西。我们会在后面详细讲。不能理解的话，就先把这部分当做“固定格式”好了。
3. main函数下面用一对大括号（花括号）包含了一段代码。这就是main函数的内容。
4. ```printf("Hello World!");```这句代码完成了输出“Hello World!”的工作。我们来关注几个重要的点。
	- printf也是一个函数，就像main一样。它的功能是输出内容。在使用它时，需要在名称后跟一对括号。
	- 括号内的内容被称作“参数”。这里的参数是"Hello World!"，也就是我们希望输出的内容。
	- 最后的分号不要忘记，是告诉电脑我们完成了一个任务。
5. ```return 0```的意思是让main函数返回0，意思是我们这个函数没有错误。
以上就是Hello World程序的全部内容。或许你还有很多没理解，没关系，先跟着一起把这段代码写完，保存，编译运行。如果没有任何报错，恭喜你！你已经通过了学C语言的第一关。
在Dev-C++中，编译运行的快捷键是F11。
